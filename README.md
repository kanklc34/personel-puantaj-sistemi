# 📊 Personel Puantaj Takip Sistemi

İnternet bağlantısı gerektirmeyen, tarayıcı tabanlı ve tamamen ücretsiz bir personel maaş/puantaj takip uygulamasıdır. İşçilerin günlük çalışma durumlarını kaydedebilir, maaş hesaplayabilir ve Excel raporu alabilirsiniz.

🔗 **Canlı Demo:** [Projeyi İncelemek İçin Tıklayın]([https://bit.ly/puantajsistem](https://kanklc34.github.io/personel-puantaj-sistemi/))

## 🚀 Özellikler

* **Personel Yönetimi:** Sınırsız sayıda personel ekleme/silme.
* **Puantaj Takibi:** Günlük yevmiye girişi (Tam Gün, Yarım Gün, Gelmedi).
* **Otomatik Hesaplama:** Toplam hak edişi anlık hesaplar.
* **Excel Çıktısı:** Verileri tek tıkla `.xlsx` formatında indirir (SheetJS ile).
* **Veri Kaydı:** `localStorage` kullanarak verileri tarayıcıda saklar (Sayfa yenilense de gitmez).
* **Karanlık Mod:** Göz yormayan gece modu desteği.
* **PWA Desteği:** Telefona uygulama gibi kurulabilir, internetsiz çalışır.

## 🛠️ Kullanılan Teknolojiler

* **HTML5 & CSS3:** Modern ve Responsive (Mobil Uyumlu) tasarım.
* **JavaScript (ES6+):** Tüm hesaplama ve DOM manipülasyonu işlemleri.
* **LocalStorage:** Veritabanı kullanmadan veri saklama.
* **SheetJS:** Excel raporlama kütüphanesi.
* **PWA (Progressive Web App):** Mobil uygulama deneyimi için.

## 📱 Nasıl Kullanılır? (Kurulum)

Bu proje web tabanlıdır, herhangi bir kurulum gerektirmez.

1.  Yukarıdaki **Canlı Demo** linkine tıklayın.
2.  "Personel Ekle" butonundan işçi ismini ve günlük ücretini girin.
3.  Takvimden günleri seçerek puantaj girin.
4.  Ay sonunda "Excel İndir" diyerek raporunuzu alın.
5.  *İpucu:* Telefonunuzda tarayıcı menüsünden "Ana Ekrana Ekle" diyerek uygulama gibi kullanabilirsiniz.
